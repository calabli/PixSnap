# PixSnap

原生 macOS 截图工具（macOS 14+，Swift 6 / AppKit）。

## 构建与运行

```bash
scripts/build-app.sh debug --run
```

脚本用 SwiftPM 编译，打包成 `build/PixSnap.app`，用钥匙串里的 “Apple Development” 证书签名（没有证书时改用临时签名），然后启动。

运行测试：

```bash
swift test
```

也可以用 Xcode 直接打开 `Package.swift` 编辑代码。

打安装包（同时支持 Apple 芯片和 Intel，输出 `build/PixSnap-<版本>.dmg`）：

```bash
scripts/package-dmg.sh
```

也可以打成安装器格式（`build/PixSnap-<版本>.pkg`，用系统“安装器”打开，有介绍页、进度条和完成页，装进“应用程序”）：

```bash
scripts/package-pkg.sh
```

现在用开发证书签名、没有公证，别的 Mac 第一次打开会被拦下：在“系统设置 › 隐私与安全性”底部点“仍要打开”。

## 首次使用

1. 按 ⌘⇧2，或点菜单栏图标 › 截取区域。
2. macOS 会提示授予“屏幕录制”权限：在“系统设置 › 隐私与安全性 › 屏幕与系统录音”里打开 PixSnap，然后重新启动 PixSnap。
3. 用固定证书签名时，重新编译后权限仍然保留；临时签名每次编译后都要重新授权。

## 当前功能（MVP 进行中）

- 菜单栏常驻，六种截图方式，各有全局快捷键（设置里都可以改，和其他截图方式重复或被别的应用占用会提示）：截取区域 ⌘⇧2、全屏截图 ⌥⇧1、长截图 ⌥⇧2、延时截图 ⌥⇧3、截取窗口 ⌥⇧4、录屏 ⌥⇧5
- 录屏：先框选区域或单击一个窗口，区域外框变红、周围变暗，旁边的小条显示录制时长、“停止”和“取消”；点“停止”或再按一次录屏快捷键结束（不占用 Esc，录的内容里可能要用到）。用 ScreenCaptureKit 录成 H.264 的 MP4（最长边超过 3840 像素时按比例缩小），只排除录屏自己的红框和控制条，晾衣架、浮动截图、编辑器等 PixSnap 窗口都能录进去。录完弹出结果窗口循环播放（有“删除”按钮，点两下从历史里永久删除），可以存为视频（MP4）、存为 GIF（15 帧/秒、最宽 800 像素、无限循环）或拖到其他应用；保存时和截图一样弹出“保存到”窗口（或直接存进保存位置）。录屏和截图一样存进历史（MP4 放在历史文件夹里，另有封面和一段小的循环缩略图）：在晾衣架上挂着循环播放，左下角有“▶ 0:12”标记；空格预览时播放视频；点一下打开播放窗口（可存为视频或 GIF）；拖出去是 MP4 文件；收藏、扔进洗衣篮、永久删除都和截图一样；菜单栏“最近截图”里写着“录屏 ·”。关闭截图历史时，没保存的录屏一天后自动清理。设置 › 录屏可以选帧率（30 / 60）和是否录制鼠标指针
- 全屏截图：直接截下鼠标所在的整块屏幕，缩到一半大小浮在屏幕中间，存进历史
- 延时截图：先像普通截图一样框选区域（或单击一个窗口），框保持高亮、周围变暗，框旁边倒计时 3、2、1（设置里可选 3 / 5 / 10 秒，按 Esc 取消）；这段时间可以在框里打开菜单、悬停出提示或等动画播到想要的那一帧，时间到了自动截下框里当时的画面，浮在原位置并存进历史
- 截取窗口：按快捷键截鼠标下的窗口，或在选区界面单击高亮的窗口；只截这一个窗口（挡在前面的其他窗口不会进来），圆角外是透明的。设置 › 窗口截图里可以选：保留窗口阴影（照 macOS 窗口的样子画一圈柔和的阴影），以及背景（无（透明）、晨曦、海洋、薄荷、薰衣草、石墨渐变或白色，四周留 56pt 边距）
- 长截图（菜单栏 › 长截图，或 ⌥⇧2）：像普通截图一样选一个区域，然后用鼠标滚轮或触控板在框里上下滚动内容（往下滚接到下面，往上滚接到上面，滚回已经截过的地方不会重复）；区域外变暗、框线流动，PixSnap 每秒截这块区域约 8 次，把新出现的内容接到下面，旁边实时显示拼好的长图。网页的固定标题栏和底栏只保留一份；滚太快会提示“跟丢了”，往回滚一点就能接上；最长 40000 像素。按回车或“完成”结束，长图缩小到屏幕能放下的大小浮在屏幕上（可以标注、复制、保存、拖出），也存进历史；Esc 或“取消”放弃
- 文字识别和搜索：每张截图（录屏用封面）存进历史后，在这台 Mac 上用系统的文字识别（Vision，中文简繁和英文，按每张图自动判断语言）识别里面的文字，存进历史数据库；以前的截图会在启动后在后台补上。晾衣架展开后，刘海下面有搜索框（点一下或 ⌘F），输入文字或应用名，只留下包含它的截图（每个词都要出现，不分大小写，按日期分组，显示有结果的最近 3 天），旁边显示“找到 N 张”；Esc 先清空再退出搜索框。选取文字：浮动截图操作栏的“选取文字”按钮（钉住时在右键菜单里）打开系统的“实况文本”，图里的文字会高亮浮起，可以像文档一样拖动选择、双击选词，⌘C 复制选中的文字（什么都没选时复制全部），右键也有“拷贝”；再点一下按钮或按 Esc 退出，选择画笔等标注工具时也会自动退出。复制全部文字：晾衣架右键菜单“复制文字”、鼠标停在照片上或预览时按 ⌘C。设置 › 截图历史里可以关掉文字识别
- 大爆炸：浮动截图操作栏的“大爆炸”按钮（✨，钉住时在右键菜单里），或晾衣架上右键“大爆炸”、鼠标停在照片上或预览时按 B。识别图里的文字，用系统分词切成一个个词和标点，每个词从它在图里的位置飞出、弹到屏幕中间排成一块块方块（背景模糊变暗）。点一下选中或取消，按住拖过多个词一起选（从已选的词开始拖则是取消）；下面的条显示“已选 N / 总数”，可以全选、复制（按原文拼回去：英文和数字之间加空格，中文不加，换行处换行）、搜索（用默认浏览器搜必应）；⌘A 全选、⌘C 复制，Esc 或点空白处关闭
- 截图历史：每次截图自动保存原图（HEIC）、缩略图和记录（时间、尺寸、来源应用），存在 `~/Library/Application Support/PixSnap/History/`（记录在 SQLite 里）；菜单栏 › 最近截图 显示最近 8 张，点一下重新浮动到屏幕上；设置里可以关闭历史、选保留时长（7 / 30 / 90 天 / 永久，默认 30 天，收藏的不清理；洗衣篮里的 7 天后删除）、查看占用空间、清空历史
- 截图翻译：浮动截图操作栏的“翻译”按钮（钉住时在右键菜单里）。识别图里的文字，把换行拆开的句子合成一段，用 macOS 自带的翻译在本机译成简体中文、English、日本語、한국어、Français、Deutsch 或 Español（中文默认译成英文，其他默认译成简体中文，记住上次选的语言），译文按原来的位置写回图上，背景色和文字颜色从原图取，标题用粗体。窗口里可以切换译文 / 原文、复制图片、复制译文、保存，或“放到屏幕上”生成一张新的浮动截图并存进历史。需要 macOS 15；第一次用某种语言时系统会提示下载语言包
- 晾衣架：从刘海往下拉（没有刘海的屏幕顶部中间有一条小黑条）打开截图历史；没有背景，只有从屏幕左边拉到右边的绳子：每天一根（最近 3 天，今天在最上面），截图像照片一样夹在绳上（像真的照片夹：绳子穿过夹子上部的凹槽，夹子下端夹住照片上沿，绳子和照片之间留一点空隙；横的和方的照片用左右两个夹子夹住、顺着绳子的坡度挂平，竖的用中间一个夹子、会轻轻摆动；照片之间和绳子两端至少留 32pt），按截图本身的比例显示（宽的、方的、竖的都不变形），绳上照片越少挂得越大（同一根绳上高度一致，最高 420pt，按屏幕高度和天数分配，不超过截图原本的大小；大照片从原图生成清晰的图），最新的在右边，轻轻晃动，打开时会掉下来弹一下；悬停晃得更快，点一下浮动到屏幕上；按空格预览鼠标下的那张（没有悬停时预览最新一张）：图片从绳上放大到屏幕中间，下面显示时间、来源应用和尺寸，← → 切换，回车或点图片浮动到屏幕上，空格、Esc 或点旁边关闭。删除像真的晾衣架一样：鼠标移到夹子上，夹子会微微张开、光标变成手形，点一下夹子就松开（夹子留在绳上）：两个夹子的照片先松开这一边，照片荡下来挂在另一个夹子上，再点另一个夹子才掉下去；照片掉进屏幕底部的洗衣篮；鼠标停在照片上或预览时按 Delete 也一样。拖动照片不会删除：拖一小段只会拽得晃一下再弹回去，拖远一点（30pt）就变成文件跟着鼠标走，晾衣架同时收起，整个屏幕都能放；放进其他应用后晾衣架保持收起，没被接住就重新放下来；预览大图也可以直接拖出去。拖出去的文件临时存在缓存里，一天后自动清理。洗衣篮里的截图保留 7 天，最新几张从篮口露出来；点篮子打开，点一张挂回绳上，鼠标移上去点右上角的 ×（再点一次确认）或右键“永久删除”单独删掉一张，或“全部挂回去”、“倒掉篮子”（再点一次确认才真正删除）；⌘Z 把刚扔的挂回去。要真正删除（不进洗衣篮、不能撤销），在照片上右键选“永久删除…”，或鼠标停在照片上、预览时按 ⌥⌘⌫，确认后照片原地消散。收藏：鼠标停在照片上或预览时按 F，或右键菜单（收藏、预览、浮动到屏幕上、扔进洗衣篮）；收藏的照片换成带金属弹簧的木夹子，点夹子或按 Delete 会摇头并提示先取消收藏；预览里显示“★ 已收藏”。浮动截图的操作栏有收藏按钮（星标），钉住后在右键菜单里；菜单栏“最近截图”里收藏的前面有 ★；设置里显示收藏张数。动画都用系统弹簧（和 SwiftUI 同一套），被打断时从当前位置接着走：预览从绳上的照片放大出来、背景模糊变暗，← → 左右滑动切换，关闭时缩回照片；夹子松开后照片按重力抛物线掉进篮子（按 Delete 时先轻轻往上一跳）；倒掉篮子时篮子往左翻倒、照片撒出来消散，再晃一下立正。开启了系统“播放用户界面音效”时会播放访达的扔废纸篓和清倒废纸篓音效。悬停刘海会变大并提示；按住往下拉，绳子跟着从屏幕顶部滑下来，超过 90pt 松手、或者单击刘海就会展开；按 Esc、点空白处（点击会穿透到下面的窗口）或再点一下刘海收起。也可以从菜单栏 › 打开晾衣架。设置里可以关闭“从刘海往下拉”；设置 › 晾衣架 可以选绳子的粗细（细 / 中 / 粗 / 特粗）、颜色（6 种预设或自定义）和材质（棉绳、麻绳、金属丝、会闪的彩灯串），带实时预览
- 设置（菜单栏 › 设置…，⌘,）：自定义截图快捷键（需要 ⌘、⌥ 或 ⌃，F1–F12 可单独使用；被占用时会提示）、截图后是否自动复制（默认关闭）、点“保存”时是否选择保存位置（默认打开）、保存位置（默认“图片/PixSnap”，选过的文件夹会记下来）、登录时打开
- 截图时先冻结屏幕，再在静止画面上选择；支持多显示器和 Retina
- 拖动选择区域，或单击自动高亮的窗口；显示像素尺寸；Esc 或右键取消
- 选区放大镜：光标旁显示放大 8 倍的周围像素、像素坐标和颜色值；按 C 复制颜色（如 #3A7BD5）并退出截图
- 截完的图浮动在原位置，可以拖到屏幕任意位置；可以同时浮动多张
- 图下方的操作栏默认隐藏，单击图片显示、再单击隐藏（按标注快捷键 R、A、T 等也会显示）；一排只有图标的按钮（鼠标停 0.35 秒显示名字和说明）：常用标注（矩形、箭头、画笔、荧光笔、文字、马赛克、序号）和撤销，直接画在浮动的图上；再点一次当前工具回到拖动模式；缩放（− 和 + 按 10%–400% 的档位缩放，中间的百分比点一下回到 100%；也可以 ⌘+ / ⌘− / ⌘0 或在触控板上双指捏合，左上角保持不动）；然后是钉住、编辑模式、复制（PNG + TIFF 到剪贴板）、保存（弹出“保存到”窗口选择文件夹和文件名，下次从上次选的文件夹打开；设置里可以改成直接存进保存位置）、拖出（按住拖到微信、邮件、访达等应用，得到带标注的 PNG 文件；也可以按住 ⌘ 拖图片，钉住时也行）、删除（从截图历史里永久删除，连同原图和缩略图，不进洗衣篮；第一次点变成红色的“确认”，3 秒内再点一次才删除；钉住时在右键菜单“永久删除…”里，会先弹窗确认；已经用“保存”存到别处的文件不受影响）、关闭；双击图片进入编辑模式；Esc 先取消工具，再按一次关闭
- 钉住（图钉）：隐藏操作栏，只留图片置顶在屏幕上，可以拖动；鼠标悬停时右上角出现图钉，点它取消钉住；右键菜单里有取消钉住、编辑模式、复制、保存、关闭
- 编辑模式（完整编辑器）：标注会带过去并保持可编辑；复制、保存后不关闭；点“退出编辑”（或 Esc、回车、⌘W、红色按钮）后截图连同标注继续浮在屏幕上
- 编辑模式工具：选择/移动（V）、矩形（R）、椭圆（O）、箭头（A）、直线（L）、画笔（P，手绘线条自动平滑）、荧光笔（H，半透明加宽、叠在文字上仍可读）、文字（T）、序号（N）、马赛克（M）、模糊（B）、放大镜（G，从中心拖出圆形镜片，放大 2 倍）、裁剪（C）；按住 Shift：直线和箭头吸附到 45°，椭圆变正圆，矩形变正方形；6 种颜色、3 档粗细；选中后改颜色和粗细、Delete 删除、双击文字重新编辑；⌘Z / ⇧⌘Z 撤销重做，⌘C 复制，⌘S 保存
- 开发调试：`PixSnap --edit <图片路径>` 用编辑器打开图片，`PixSnap --pin <图片路径> [--pinned] [--bar] [--select-text] [--bigbang]` 把图片浮动在屏幕中间（加 `--pinned` 直接钉住，加 `--bar` 直接显示操作栏，加 `--select-text` 直接进入选取文字，加 `--bigbang` 直接大爆炸，加 `--beautify` 直接美化，加 `--translate` 直接翻译，再加 `--fake-translation` 用占位译文、不需要语言包），`PixSnap --history-dir <文件夹>` 把截图历史放到别的文件夹（拍演示截图用），`PixSnap --settings` 启动后直接打开设置，`PixSnap --capture region|fullScreen|scrolling|delayed|window|recording` 启动后直接用这种方式截图，`PixSnap --record x,y,w,h 秒数 [输出.gif]` 对这块区域录屏，到时间自动停止（给了 .gif 路径就同时导出 GIF），`PixSnap --delayed-capture x,y,w,h` 对这块区域（全局坐标）直接开始倒计时并截图，`PixSnap --history-add <图片路径>` 把图片当作一次截图存进历史，`PixSnap --clothesline [--preview | --basket | --throw | --search 文字]` 启动后直接打开晾衣架（加 `--preview` 同时预览最新一张，`--basket` 打开洗衣篮，`--throw` 把最新一张扔进洗衣篮，`--search` 直接搜索），`PixSnap --overlay <图片路径>` 在图片上显示选区界面，`PixSnap --scroll-capture x,y,w,h 秒数 输出.png` 对这块区域（全局坐标）做长截图，到时间自动完成并写入 PNG

## 多屏和全屏

- 每块屏幕单独显示选区界面，选区不能跨屏；光标所在的屏幕先截、先显示
- 刘海屏：选区尺寸和放大镜不会被刘海挡住
- 选区界面、浮动截图、编辑模式和设置都能出现在全屏应用和所有桌面（空间）上
- 截图过程中插拔显示器会取消这次截图；留在被拔掉的显示器上的浮动截图会移回主屏幕中间
- 屏幕坐标换算和多屏顺序有单元测试（`ScreenGeometryTests`，按内置屏 + 上方外接屏的布局）

## 性能

目标：按下快捷键到光标所在屏幕出现选区界面 ≤ 100ms。每次截图的各阶段耗时会写进系统日志（子系统 `com.pixsnap.PixSnap`，类别 `performance`）。

测量（release 版，连续截图 20 次，结果写入文件后自动退出；期间屏幕会闪几下，不保存任何截图）：

```bash
scripts/build-app.sh release && open build/PixSnap.app --args --benchmark-capture 20 --benchmark-output /tmp/pixsnap-benchmark.txt
```

2026-10-27 在双屏 Mac 上：优化前热启动中位数 146ms、p90 155ms、首次 223ms；优化后中位数 63ms、p90 77ms、首次 92ms。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `Sources/PixSnapCore` | 与平台无关的逻辑（选区几何、多屏坐标、文件命名、标注数据模型、撤销重做、历史数据库、晾衣架绳子样式和布局、长截图拼接），以后可与 Windows 版共享 |
| `Sources/PixSnapRender` | 用 Core Graphics 绘制标注，编辑器画布和导出图片共用同一套代码 |
| `Sources/PixSnap` | macOS 应用：菜单栏、快捷键、ScreenCaptureKit 截图、选区界面、浮动截图、标注编辑器 |
| `Tests/PixSnapCoreTests` | 核心模块单元测试 |
| `scripts/build-app.sh` | 编译、打包、签名、启动 |
