# PixSnap

原生 macOS 截图工具（macOS 14+，Swift 6 / AppKit）。

## 构建与运行

```bash
scripts/build-app.sh debug --run
```

脚本用 SwiftPM 编译，打包成 `build/PixSnap.app`，用钥匙串里的 “Apple Development” 证书签名（没有证书时改用临时签名），然后启动。

运行测试：

```bash
swift test
```

也可以用 Xcode 直接打开 `Package.swift` 编辑代码。

## 首次使用

1. 按 ⌘⇧2，或点菜单栏图标 › 截取区域。
2. macOS 会提示授予“屏幕录制”权限：在“系统设置 › 隐私与安全性 › 屏幕与系统录音”里打开 PixSnap，然后重新启动 PixSnap。
3. 用固定证书签名时，重新编译后权限仍然保留；临时签名每次编译后都要重新授权。

## 当前功能（MVP 进行中）

- 菜单栏常驻，全局快捷键默认 ⌘⇧2
- 长截图（菜单栏 › 长截图，或 ⌥⇧2）：像普通截图一样选一个区域，然后用鼠标滚轮或触控板在框里往下滚动内容；区域外变暗、框线流动，PixSnap 每秒截这块区域约 8 次，把新出现的内容接到下面，旁边实时显示拼好的长图。网页的固定标题栏和底栏只保留一份；滚太快或往上滚会提示“跟丢了”，往回滚一点就能接上；最长 40000 像素。按回车或“完成”结束，长图缩小到屏幕能放下的大小浮在屏幕上（可以标注、复制、保存、拖出），也存进历史；Esc 或“取消”放弃
- 截图历史：每次截图自动保存原图（HEIC）、缩略图和记录（时间、尺寸、来源应用），存在 `~/Library/Application Support/PixSnap/History/`（记录在 SQLite 里）；菜单栏 › 最近截图 显示最近 8 张，点一下重新浮动到屏幕上；设置里可以关闭历史、选保留时长（7 / 30 / 90 天 / 永久，默认 30 天，收藏的不清理；洗衣篮里的 7 天后删除）、查看占用空间、清空历史
- 晾衣架：从刘海往下拉（没有刘海的屏幕顶部中间有一条小黑条）打开截图历史；没有背景，只有从屏幕左边拉到右边的绳子：每天一根（最近 3 天，今天在最上面），截图像照片一样夹在绳上（像真的照片夹：绳子穿过夹子上部的凹槽，夹子下端夹住照片上沿，绳子和照片之间留一点空隙；横的和方的照片用左右两个夹子夹住、顺着绳子的坡度挂平，竖的用中间一个夹子、会轻轻摆动；照片之间和绳子两端至少留 32pt），按截图本身的比例显示（宽的、方的、竖的都不变形），绳上照片越少挂得越大（同一根绳上高度一致，最高 420pt，按屏幕高度和天数分配，不超过截图原本的大小；大照片从原图生成清晰的图），最新的在右边，轻轻晃动，打开时会掉下来弹一下；悬停晃得更快，点一下浮动到屏幕上；按空格预览鼠标下的那张（没有悬停时预览最新一张）：图片从绳上放大到屏幕中间，下面显示时间、来源应用和尺寸，← → 切换，回车或点图片浮动到屏幕上，空格、Esc 或点旁边关闭。删除像真的晾衣架一样：鼠标移到夹子上，夹子会微微张开、光标变成手形，点一下夹子就松开（夹子留在绳上）：两个夹子的照片先松开这一边，照片荡下来挂在另一个夹子上，再点另一个夹子才掉下去；照片掉进屏幕底部的洗衣篮；鼠标停在照片上或预览时按 Delete 也一样。拖动照片不会删除：拖一小段只会拽得晃一下再弹回去，拖远一点（30pt）就变成文件跟着鼠标走，晾衣架同时收起，整个屏幕都能放；放进其他应用后晾衣架保持收起，没被接住就重新放下来；预览大图也可以直接拖出去。拖出去的文件临时存在缓存里，一天后自动清理。洗衣篮里的截图保留 7 天，最新几张从篮口露出来；点篮子打开，点一张挂回绳上，或“全部挂回去”、“倒掉篮子”（再点一次确认才真正删除）；⌘Z 把刚扔的挂回去。收藏：鼠标停在照片上或预览时按 F，或右键菜单（收藏、预览、浮动到屏幕上、扔进洗衣篮）；收藏的照片换成带金属弹簧的木夹子，点夹子或按 Delete 会摇头并提示先取消收藏；预览里显示“★ 已收藏”。浮动截图的操作栏有收藏按钮（星标），钉住后在右键菜单里；菜单栏“最近截图”里收藏的前面有 ★；设置里显示收藏张数。动画都用系统弹簧（和 SwiftUI 同一套），被打断时从当前位置接着走：预览从绳上的照片放大出来、背景模糊变暗，← → 左右滑动切换，关闭时缩回照片；夹子松开后照片按重力抛物线掉进篮子（按 Delete 时先轻轻往上一跳）；倒掉篮子时篮子往左翻倒、照片撒出来消散，再晃一下立正。开启了系统“播放用户界面音效”时会播放访达的扔废纸篓和清倒废纸篓音效。悬停刘海会变大并提示；按住往下拉，绳子跟着从屏幕顶部滑下来，超过 90pt 松手、或者单击刘海就会展开；按 Esc、点空白处（点击会穿透到下面的窗口）或再点一下刘海收起。也可以从菜单栏 › 打开晾衣架。设置里可以关闭“从刘海往下拉”；设置 › 晾衣架 可以选绳子的粗细（细 / 中 / 粗 / 特粗）、颜色（6 种预设或自定义）和材质（棉绳、麻绳、金属丝、会闪的彩灯串），带实时预览
- 设置（菜单栏 › 设置…，⌘,）：自定义截图快捷键（需要 ⌘、⌥ 或 ⌃，F1–F12 可单独使用；被占用时会提示）、截图后是否自动复制（默认关闭）、点“保存”时是否选择保存位置（默认打开）、保存位置（默认“图片/PixSnap”，选过的文件夹会记下来）、登录时打开
- 截图时先冻结屏幕，再在静止画面上选择；支持多显示器和 Retina
- 拖动选择区域，或单击自动高亮的窗口；显示像素尺寸；Esc 或右键取消
- 选区放大镜：光标旁显示放大 8 倍的周围像素、像素坐标和颜色值；按 C 复制颜色（如 #3A7BD5）并退出截图
- 截完的图浮动在原位置，可以拖到屏幕任意位置；可以同时浮动多张
- 图下方一排按钮：常用标注（矩形、箭头、文字、马赛克、序号）和撤销，直接画在浮动的图上；再点一次当前工具回到拖动模式；然后是钉住、编辑模式、复制（PNG + TIFF 到剪贴板）、保存（弹出“保存到”窗口选择文件夹和文件名，下次从上次选的文件夹打开；设置里可以改成直接存进保存位置）、拖出（按住拖到微信、邮件、访达等应用，得到带标注的 PNG 文件；也可以按住 ⌘ 拖图片，钉住时也行）、关闭；双击图片进入编辑模式；Esc 先取消工具，再按一次关闭
- 钉住（图钉）：隐藏操作栏，只留图片置顶在屏幕上，可以拖动；鼠标悬停时右上角出现图钉，点它取消钉住；右键菜单里有取消钉住、编辑模式、复制、保存、关闭
- 编辑模式（完整编辑器）：标注会带过去并保持可编辑；复制、保存后不关闭；点“退出编辑”（或 Esc、回车、⌘W、红色按钮）后截图连同标注继续浮在屏幕上
- 编辑模式工具：选择/移动（V）、矩形（R）、箭头（A）、文字（T）、序号（N）、马赛克（M）、裁剪（C）；6 种颜色、3 档粗细；选中后改颜色和粗细、Delete 删除、双击文字重新编辑；⌘Z / ⇧⌘Z 撤销重做，⌘C 复制，⌘S 保存
- 开发调试：`PixSnap --edit <图片路径>` 用编辑器打开图片，`PixSnap --pin <图片路径> [--pinned]` 把图片浮动在屏幕中间（加 `--pinned` 直接钉住），`PixSnap --settings` 启动后直接打开设置，`PixSnap --history-add <图片路径>` 把图片当作一次截图存进历史，`PixSnap --clothesline [--preview | --basket | --throw]` 启动后直接打开晾衣架（加 `--preview` 同时预览最新一张，`--basket` 打开洗衣篮，`--throw` 把最新一张扔进洗衣篮），`PixSnap --overlay <图片路径>` 在图片上显示选区界面，`PixSnap --scroll-capture x,y,w,h 秒数 输出.png` 对这块区域（全局坐标）做长截图，到时间自动完成并写入 PNG

## 多屏和全屏

- 每块屏幕单独显示选区界面，选区不能跨屏；光标所在的屏幕先截、先显示
- 刘海屏：选区尺寸和放大镜不会被刘海挡住
- 选区界面、浮动截图、编辑模式和设置都能出现在全屏应用和所有桌面（空间）上
- 截图过程中插拔显示器会取消这次截图；留在被拔掉的显示器上的浮动截图会移回主屏幕中间
- 屏幕坐标换算和多屏顺序有单元测试（`ScreenGeometryTests`，按内置屏 + 上方外接屏的布局）

## 性能

目标：按下快捷键到光标所在屏幕出现选区界面 ≤ 100ms。每次截图的各阶段耗时会写进系统日志（子系统 `com.pixsnap.PixSnap`，类别 `performance`）。

测量（release 版，连续截图 20 次，结果写入文件后自动退出；期间屏幕会闪几下，不保存任何截图）：

```bash
scripts/build-app.sh release && open build/PixSnap.app --args --benchmark-capture 20 --benchmark-output /tmp/pixsnap-benchmark.txt
```

2026-10-27 在双屏 Mac 上：优化前热启动中位数 146ms、p90 155ms、首次 223ms；优化后中位数 63ms、p90 77ms、首次 92ms。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `Sources/PixSnapCore` | 与平台无关的逻辑（选区几何、多屏坐标、文件命名、标注数据模型、撤销重做、历史数据库、晾衣架绳子样式和布局、长截图拼接），以后可与 Windows 版共享 |
| `Sources/PixSnapRender` | 用 Core Graphics 绘制标注，编辑器画布和导出图片共用同一套代码 |
| `Sources/PixSnap` | macOS 应用：菜单栏、快捷键、ScreenCaptureKit 截图、选区界面、浮动截图、标注编辑器 |
| `Tests/PixSnapCoreTests` | 核心模块单元测试 |
| `scripts/build-app.sh` | 编译、打包、签名、启动 |
