# PixSnap

原生 macOS 截图工具（macOS 14+，Swift 6 / AppKit）。

## 构建与运行

```bash
scripts/build-app.sh debug --run
```

脚本用 SwiftPM 编译，打包成 `build/PixSnap.app`，用钥匙串里的 “Apple Development” 证书签名（没有证书时改用临时签名），然后启动。

运行测试：

```bash
swift test
```

也可以用 Xcode 直接打开 `Package.swift` 编辑代码。

## 首次使用

1. 按 ⌘⇧2，或点菜单栏图标 › 截取区域。
2. macOS 会提示授予“屏幕录制”权限：在“系统设置 › 隐私与安全性 › 屏幕与系统录音”里打开 PixSnap，然后重新启动 PixSnap。
3. 用固定证书签名时，重新编译后权限仍然保留；临时签名每次编译后都要重新授权。

## 当前功能（MVP 进行中）

- 菜单栏常驻，全局快捷键默认 ⌘⇧2
- 设置（菜单栏 › 设置…，⌘,）：自定义截图快捷键（需要 ⌘、⌥ 或 ⌃，F1–F12 可单独使用；被占用时会提示）、截图后是否自动复制（默认关闭）、保存位置（默认“图片/PixSnap”）、登录时打开
- 截图时先冻结屏幕，再在静止画面上选择；支持多显示器和 Retina
- 拖动选择区域，或单击自动高亮的窗口；显示像素尺寸；Esc 或右键取消
- 选区放大镜：光标旁显示放大 8 倍的周围像素、像素坐标和颜色值；按 C 复制颜色（如 #3A7BD5）并退出截图
- 截完的图浮动在原位置，可以拖到屏幕任意位置；可以同时浮动多张
- 图下方一排按钮：常用标注（矩形、箭头、文字、马赛克、序号）和撤销，直接画在浮动的图上；再点一次当前工具回到拖动模式；然后是编辑模式、复制（PNG + TIFF 到剪贴板）、保存到“图片/PixSnap”、关闭；双击图片进入编辑模式；Esc 先取消工具，再按一次关闭
- 编辑模式（完整编辑器）：标注会带过去并保持可编辑；复制、保存后不关闭；点“退出编辑”（或 Esc、回车、⌘W、红色按钮）后截图连同标注继续浮在屏幕上
- 编辑模式工具：选择/移动（V）、矩形（R）、箭头（A）、文字（T）、序号（N）、马赛克（M）、裁剪（C）；6 种颜色、3 档粗细；选中后改颜色和粗细、Delete 删除、双击文字重新编辑；⌘Z / ⇧⌘Z 撤销重做，⌘C 复制，⌘S 保存
- 开发调试：`PixSnap --edit <图片路径>` 用编辑器打开图片，`PixSnap --pin <图片路径>` 把图片浮动在屏幕中间，`PixSnap --settings` 启动后直接打开设置，`PixSnap --overlay <图片路径>` 在图片上显示选区界面

## 多屏和全屏

- 每块屏幕单独显示选区界面，选区不能跨屏；光标所在的屏幕先截、先显示
- 刘海屏：选区尺寸和放大镜不会被刘海挡住
- 选区界面、浮动截图、编辑模式和设置都能出现在全屏应用和所有桌面（空间）上
- 截图过程中插拔显示器会取消这次截图；留在被拔掉的显示器上的浮动截图会移回主屏幕中间
- 屏幕坐标换算和多屏顺序有单元测试（`ScreenGeometryTests`，按内置屏 + 上方外接屏的布局）

## 性能

目标：按下快捷键到光标所在屏幕出现选区界面 ≤ 100ms。每次截图的各阶段耗时会写进系统日志（子系统 `com.pixsnap.PixSnap`，类别 `performance`）。

测量（release 版，连续截图 20 次，结果写入文件后自动退出；期间屏幕会闪几下，不保存任何截图）：

```bash
scripts/build-app.sh release && open build/PixSnap.app --args --benchmark-capture 20 --benchmark-output /tmp/pixsnap-benchmark.txt
```

2026-10-27 在双屏 Mac 上：优化前热启动中位数 146ms、p90 155ms、首次 223ms；优化后中位数 63ms、p90 77ms、首次 92ms。

## 代码结构

| 路径 | 内容 |
| --- | --- |
| `Sources/PixSnapCore` | 与平台无关的逻辑（选区几何、文件命名、标注数据模型、撤销重做），以后可与 Windows 版共享 |
| `Sources/PixSnapRender` | 用 Core Graphics 绘制标注，编辑器画布和导出图片共用同一套代码 |
| `Sources/PixSnap` | macOS 应用：菜单栏、快捷键、ScreenCaptureKit 截图、选区界面、浮动截图、标注编辑器 |
| `Tests/PixSnapCoreTests` | 核心模块单元测试 |
| `scripts/build-app.sh` | 编译、打包、签名、启动 |
